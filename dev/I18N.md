# The mod in other languages

Issue 127 (a Nexus user asked for translation). Modelled on SkyrimFollowerTactics' `dev/I18N.md`: English is the source and the key, a catalog is a flat JSON file per language, and a tool keeps the catalogs in step with the source. A catalog comes with it for each language the game ships talk tables for (`core_<locale>.tlk` in the GOG install): `en-US` (the list itself), `es-ES`, `de-DE`, `fr-FR`, `it-IT`, `cs-CZ`, `pl-PL`, `ru-RU` and `hu-HU`. The game's locale picks the catalog; nothing is set by the player. Chinese and Japanese are not in the GOG install, so there is no catalog for them. Spanish was seen in game (the turn bar's buttons and caption); the rest were not, and none was read by a native speaker: all eight are the agent's.

## What is translated

The mod's own words, where the player reads them:

- the turn bar's movie (`ui/turnorder`): the Delay and End buttons, "waits", the arrows' "N turns before these", the caption under the bar (time left, the cost of the order under the cursor, "Paused", an action that lands next turn), the movement preview's plate;
- the messages that float over a character and the caption's notice of an order given back (`src/core`: `TurnMachine.cpp`, `GivenBack.cpp`);
- the character sheet's section headings (`Sheet.cpp`; the stats' names are the game's own, already in the game's language);
- the Turn-based section of Options and its three Controls rows, and the messages the toggle key says (`src/plugin/Plugin.cpp`);
- the tactics page's box's caption (`ui/tactics`).

Not translated: the log and the events (English, for a bug report), names the game gives (creatures, abilities, items), the settings file's comments, and the sample data the movies draw outside the game.

## Marking a line

`src/core/I18n.h` for C++, and `tr`/`trf` at the top of each movie's `DoAction.as`. `tools/i18n.py` extracts all of them.

| | |
|---|---|
| `Tr(L"Delay")` | the line in the language in force, as a `wstring_view` (`Said(...)` in `TurnMachine.cpp` and `Plugin.cpp` makes a `wstring` of it). |
| `TrFormat(L"{} waits", name)` | translated, then formatted with `std::format`. A translation may reorder: `"{1} de {0}"`. One that does not format with the arguments is passed over for the English. |
| `N_(L"Held")` | marked only, for a literal that is translated where it is shown: the machine thinks, logs and compares in English (`Refuse`, `SayGivenBack`, `GivenBackLine` translate as they show it). |
| `tr("Delay")`, `trf("{0} s left", n)` | the same in ActionScript. `{0}`, `{1}` are filled after translation, in any order. |

Rules:

1. **Only what the player reads.** Never the log, an event's text, a key of JSON, an engine name or anything compared as a value. `Refuse` logs and emits the English and floats the translation.
2. **A sentence is one line**, not fragments joined: `TrFormat(L"{} loses the turn", name)`, never `name + L" loses the turn"`. A language may put the name first.
3. **The mark goes on the literal**: `Said(N_(L"a"))`, not `N_(cond ? L"a" : L"b")`.
4. **English plurals are two lines** (`"1 turn before these"`, `"{0} turns before these"`); a language without them translates both alike.

## Catalogs

`assets/Translations/<locale>.json`, UTF-8, `{"Delay": "Retrasar"}`. The build copies them beside the dll (`Translations\`), `tools/package.ps1` into the zip, `tools/deploy.ps1` with the plugin's folder.

    python tools/i18n.py          # rewrite assets/Translations/*.json from the source
    python tools/i18n.py --check  # exit 1 if out of step, or a translation's fields differ from the English's

`en-US.json` is the extracted list, each line its own translation: what a translator copies to start a language. Every other catalog keeps its translations for lines still marked, gains an empty entry for a new line (read in English until filled) and loses a line no longer marked. `tools/test_i18n.py` fails when a catalog is out of step, so a new line is added to the catalogs in the same commit.

To add a language: copy `en-US.json` to `<locale>.json` (`fr-FR.json`, `zh-CN.json`, ...), translate the values, run `python tools/i18n.py --check`. Nothing else needs to change: a file in `Translations\` is found by its name.

## Choosing the language

`turnbased.ini`, `[interface] language`: `auto` (the default) or a catalog's name. `auto` is the game's own language: `Locale` under `[GameOptions]` in `Documents\BioWare\Dragon Age\Settings\DragonAge.ini` (`es-es`, `de-de`; DAOLib's `dao::strings::Locale`), the setting that picks the game's own talk tables, so the mod follows the game and not Windows. The language asked for reads the catalog of its own name in any case, else one of the same language (`es-MX` and `es-ES` read `es-ES`, until they have a catalog of their own), Chinese by script (`zh-Hans` and `zh-CN`; `zh-TW` is not `zh-CN`'s), else English (`core/I18n.cpp`, `PickLocale`). A game in a language with no catalog reads English. The game ships `es-es` (Spanish), so a Spanish game reads `es-ES`. It is read once at load, before the options and the keys are added, whose names the game takes as they are given; the log says what was read (`words in es-ES ...`).

The movies ask the plugin for the catalog once, `TB_GetWords` (`game/Bar.cpp`; the tactics box asks the same call), as pairs: English, a unit separator, translation, a record separator.

## Fonts

The movies draw in the game's own fonts (`$BodyFont`, `$TitleFont`), which cover the accented Latin of the game's European languages. A language the game's fonts do not cover (Chinese, Japanese, Russian in an English-installed game) would show holes: seen only when someone makes the catalog and tests it.

## Where it stands

- Built on `gh-127-translation`: the core tests, `tools/test_i18n.py` and the catalogs' check are clean, and the plugin and both movies build. Only the Spanish turn bar has been seen in game.
- **Wording for Czech, Polish, Russian, Hungarian, French and Italian.** The Slavic languages have three plural forms and agree a verb with the gender of what it is about, so their catalogs avoid both: a label and then the number ("Tahů po těchto: {0}") for "{0} turns after these", and a noun-first notice (`{0}: возврат — {2} ({1})`) for "given back", "refused" and "not made". French and Italian use the noun-first notice too.
- **Fonts** are the game's own for its language. That the movies draw Cyrillic and the Polish, Czech and Hungarian letters is not yet seen.
- **One key, one translation.** "Attack" is both the card's pending action and a word on its own; "Casting" is a floaty and a refusal alike, and shares an entry. If a language needs two words, the fix is a context mark, not built.
- **Plurals** are English's two lines.
- `auto` follows the game's language; a player may still set one by hand.
