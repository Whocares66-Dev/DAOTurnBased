## Findings

None against the build. Two things noticed:

1. **The start-up line names the ini's key, not the bound one.** With the row bound to F10, the next start still said `Ctrl+T until bound there`. True as written, but a reader of the log learns the default and not the key in force; the debug line `the game has taken the toggle's key` could name it.
2. **A leftover line in `KeyBindings.ini`.** In the polled mode (check 8) the `TurnBasedToggle_0` line stays in the file with no row to show or change it. Harmless, and it is what brings the binding back when the ini's key is one the game takes again.

No warning, no error, no crash.
